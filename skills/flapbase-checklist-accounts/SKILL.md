# アカウントと権限の安全

この skill はパスワード・鍵・認証のコードを見ない、書かない、聞かない。確かめるのは「設定されているか」と「だれが持っているか」だけ。

## チェックリスト

1. **一覧**：事業で使うアカウント（ドメイン・メール・サイト・ストア・決済・SNS・会計・クラウドの保存・検索の道具）を、名前とだれが管理者かだけで並べる。
2. **2段階の認証**：管理者のアカウントで2段階の認証が有効か。
3. **管理者が手元にいるか**：前の担当者・外の会社・個人のアドレスのままになっていないか。事業のドメインのアドレスか。
4. **使っていない権限**：辞めた人・終わった外注先・使っていない連携（アプリの接続・API の接続）が残っていないか。外すのは持ち主。
5. **控え**：サイト・お客さまの記録・帳簿の控えがあるか。戻し方を一度試したか。
6. **通知の宛先**：大事な知らせ（請求・更新・不正のログイン）が、見ているアドレスに届くか。
7. **人の出入りのとき**：入る人には要る権限だけ、出る人の権限は当日に外す。

## Flapbase Cloud でつなぐ所

- 1・3・6：リソース管理（アカウントも資源として、期限と担当を持つ）。
- 4：Flapbase のワークスペースのメンバー・Project のゲスト・接続の一覧。
- 四半期ごとにワークフロー「アカウントの確認」として回す。

## 決まり

- パスワード・鍵・コード・復旧の手段を、記録・チャット・ファイルに書かない。
- 権限を外す・設定を変える操作は持ち主が行う。
