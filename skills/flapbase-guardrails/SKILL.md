# 守ること

## 用意するもの

依頼の範囲と、扱う情報、これから行う操作を、確認できるようにしてください。

## 始める前に

個人情報、秘密の情報、公開、決済、権限の変更が作業に含まれていないか、確かめてください。

## 手順

### 個人情報を扱わない

- 問い合わせの中身など、個人のデータを読む道具はありません。ほかの方法で取得して持ち込むこともしないでください。
- 依頼主から渡された個人情報を、工程の記録・成果物・会話の外にコピーしないでください。
- パスワード・鍵・トークンは、記録にも会話にも書かないでください。

### 人が決めること（エージェントは依頼するだけ）

| 決めること | 人が行う場所 | エージェントがすること |
| --- | --- | --- |
| 契約・同意 | 画面かメールのリンク | 内容を読んで伝える |
| 決済・プランの変更・クレジットの追加購入 | 設定の「プラン」 | 必要な額を伝える |
| クレジットを使う生成 | 見積りの金額と文の承認 | 見積りを見せ、承認後に `creditConsent` を付けて送り直す |
| 外部への公開 | Site の画面 | `site_publish_request` で依頼する |
| 成果物の受け入れ・差し戻し | 画面 | `work_item_submit` で依頼する |
| 判断の選択 | 画面 | `decision_request_create` で選択肢を示す |
| 権限の変更・メンバーの追加 | 画面 | 必要なことを伝える |
| 削除 | 画面で承認 | 削除の道具はないので、人に依頼するだけ |
| メール・配信・SNS への送信 | 人 | 送る道具はないので、送らない |

### 迷ったら

- 実行してよいか迷う操作は、実行する前に依頼主に聞いてください。
- 権限がないと断られたら、別の道具で回避しようとしないでください。何が足りないのかを、依頼主に伝えます。
- 保存した下書きは、まだ公開されていません。公開されたと伝えてはいけません。

### 事実と違うことを伝えない

- 確かめていないことは「未確認」と書いてください。道具から返ってきていない結果を、できたかのように報告してはいけません。

## チェックリスト

手順で確かめた項目を「確認済み」「未確認」「持ち主の判断待ち」に分けて書き出し、抜けがないかを確かめてください。

## 終わりの目安

エージェントだけで進められる作業と、人の判断が必要な作業を、分けて示している。

## 次にできること

承認された仕事のスキルに戻ります。

## Flapbase で続ける

なし。このスキルは、各作業の前に確かめる事項をまとめたもの。
