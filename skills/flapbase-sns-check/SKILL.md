# SNS を診断する

## 用意するもの

- 持ち主（事業の判断をする人）と話していること。
- 診断する SNS 1つ（Instagram・X など）のプロフィールの文と、最近の投稿10〜20件の本文の貼り付け。反応の数（いいね・保存・プロフィールへの訪問）が分かれば足す。
- ログインや投稿はしない。持ち主が貼った内容だけを読む。

## 始める前に

前回の診断の表があれば、同じ項目で並べ直して比べる。なければ手順の最初から始める。貼られていない情報（反応の数など）は「未確認」と書く。

## 手順

### 聞くこと

質問は一度に1つだけ。答えを受けてから次を聞く。次の順に、まだ分かっていないことだけを聞く。

1. どの SNS か、その SNS で増やしたいこと（予約・購入・問い合わせ・フォロー）
2. プロフィールの文（貼り付け）
3. 最近の投稿10〜20件の本文（貼り付け）
4. 反応の数（分かれば。投稿ごとでなくまとめてでもよい）

分からないことは「未確認」のまま進める。数を推測で埋めない。

### 結果の形

毎回、次の4つを返す。プロフィールの点検の表、投稿の種類の表、改善案（次の10本の投稿案の題と、そのまま使える投稿3本の文）、引き継ぎメモ。最後に、その日のうちにできる「先にやる1つ」と、続けるときに頼れる伴走のエージェント（SNS 集客）を1行で添える。

プロフィールの点検：

| 見る点 | 見たこと | 判定 |
| --- | --- | --- |
| 何を売るか・だれ向けか | プロフィールの文 | あり／あいまい／不足 |
| 得（買うと何が得られるか） | 同上 | 同上 |
| 次の行動（予約へのリンクなど） | 同上 | 同上 |

投稿の種類：

| 種類 | 件数 | 割合 |
| --- | --- | --- |
| 商品や景色の写真だけ・使い方・お客さまの声・告知など | 貼られた投稿を種類ごとに数えた件数 | 件数 ÷ 全体の件数 |

- 優先順位：まずプロフィールの「不足」を直す（投稿を見た人が最初に訪れる場所のため）。次に、最も偏っている投稿の種類を直す。
- 改善案の投稿3本は、店名・商品・得・次の行動が分かる文にする。雰囲気だけの一言にしない。事実（値段・日数）は、貼られた内容にあるものだけを使う。ないものは「要確認」と書く。
- 反応の数が少ない時は、種類ごとの比較を確かな結果として扱わず「数が少ない」と書く。
- 改善の見込みは数で予測しない。「何が変わるはずか」と「どう確かめるか」で書く。
- 引き継ぎメモ：事業・目標・確認した数・いちばんの問題・先にやる1つ、の短い箇条。そのまま伴走のエージェントに渡せる形にする。

### 実行の例

名前・金額・件数はどれも例（実在の事業・アカウントではない）。

**コスメ（オンラインの店・Instagram）**

受け取った情報：プロフィールの文「毎日をていねいに。」、リンクはトップのみ。直近12件の投稿の本文。反応の数は未確認。

| 見る点 | 見たこと | 判定 |
| --- | --- | --- |
| 何を売るか・だれ向けか | 「毎日をていねいに。」のみ | 不足 |
| 得 | 書かれていない | 不足 |
| 次の行動 | トップへのリンクのみ | あいまい |

| 種類 | 件数 | 割合 |
| --- | --- | --- |
| 商品の写真だけ | 8 | 67% |
| 使い方 | 2 | 17% |
| お客さまの声 | 1 | 8% |
| セールの告知 | 1 | 8% |

12件のうち8件が商品の写真だけ。いちばん伝わっていないのは、何の店かということと、買う理由（プロフィールが雰囲気だけで、中身がない）。
改善案：
- プロフィールの案：乾燥肌向けの無香料クリームの通販。30g 3,300円（税込）、未開封なら14日以内に返品できます。試供品はリンクから。
- 次の10本の投稿案の題：朝の保湿の手順／夜の保湿の手順／無香料にした理由／成分の読み方／お客さまの声（保湿の変化）／試供品の中身／よくある質問（返品）／乾燥しやすい季節の使い分け／使い切りの目安／他の保湿との重ね方
- 投稿の案（そのまま使える文）：
  1. 乾燥肌の朝の保湿は、洗顔後すぐ、クリーム豆粒2つ分。無香料クリーム 30g は3,300円（税込）。試供品は、プロフィールのリンクから申し込めます。
  2. 「香りが苦手で保湿をやめていました」というお客さまの声をいただきました。無香料クリームは、未開封なら14日以内に返品できます。詳しくはプロフィールのリンクへ。
  3. 試供品に入っているのは、クリーム 3g と使い方の紙1枚です。送料だけで届きます。申し込みはプロフィールのリンクから。
  （金額・日数・内容は例。実際の値は持ち主に確かめる。）
先にやる1つ：プロフィールを上の案に差し替える。
引き継ぎメモ：
- 事業：スキンケアの通販（Instagram）
- 目標：試供品の申し込みを増やす
- 確認した数：投稿12件のうち、商品の写真だけが8件。反応は未確認
- いちばんの問題：プロフィールに何を売るかと得がない
- 先にやる1つ：プロフィールの差し替え
続けるなら：SNS 集客（10本の案を週ごとに出し、試供品の申し込みで確かめる）。

**アパレル（小さなワンピースのブランド・Instagram）**

受け取った情報：プロフィールの文「ワンピースのお店 / 新作はハイライトから」、リンクあり。直近15件の投稿の本文。保存の数は未確認。

| 見る点 | 見たこと | 判定 |
| --- | --- | --- |
| 何を売るか・だれ向けか | 「ワンピースのお店」のみ。だれ向けかは書かれていない | あいまい |
| 得 | 書かれていない | 不足 |
| 次の行動 | ハイライトとリンクあり | あり |

| 種類 | 件数 | 割合 |
| --- | --- | --- |
| コーディネート写真 | 9 | 60% |
| 入荷の告知 | 4 | 約27% |
| 着用した人の声 | 1 | 約7% |
| サイズの案内 | 1 | 約7% |

15件のうち9件がコーディネート写真。いちばん伝わっていないのは、サイズの案内と交換の条件（1件しかない）。
改善案：
- プロフィールの案：身長155cm 前後の人向けの、丈を短めに作るワンピース専門。S〜L の3サイズ。サイズが合わなければ14日以内に1回無料で交換できます。
- 次の10本の投稿案の題：身長別の丈の見え方／S・M・L の比べ／サイズ交換の流れ／着用した人の声／素材と洗い方／1着の3通りの着回し／入荷のお知らせ（サイズの残り）／縫製の工程／よくある質問（サイズ）／お直しの案内
- 投稿の案（そのまま使える文）：
  1. 身長155cm の人が M を着ると、丈は膝下5cm ほどです。丈直しは要りません。S〜L の3サイズ。サイズ表はプロフィールのリンクから。
  2. サイズが合わなかった時は、到着後14日以内に1回だけ無料で交換できます。手順は3つ。プロフィールのリンクの「交換について」にまとめました。
  3. 新作のワンピースが入荷しました。残りは M が3点、L が2点です。ご購入はプロフィールのリンクから。
  （丈・日数・残りの数は例。実際の値は持ち主に確かめる。）
先にやる1つ：サイズの案内の投稿を、固定投稿にする。
引き継ぎメモ：
- 事業：ワンピースの通販（Instagram）
- 目標：サイズの相談から購入までを増やす
- 確認した数：投稿15件のうち、サイズの案内は1件。保存は未確認
- いちばんの問題：だれ向けかと、サイズ・交換の情報が少ない
- 先にやる1つ：サイズの案内を固定投稿にする
続けるなら：SNS 集客（サイズの投稿を続け、サイズ相談の件数で確かめる）。

**旅（少人数の体験ツアー・X）**

受け取った情報：プロフィールの文「島のガイドです。旅が好き。」、リンクは予約のページ。直近10件の投稿の本文。反応は未確認。

| 見る点 | 見たこと | 判定 |
| --- | --- | --- |
| 何を売るか・だれ向けか | 「島のガイド」のみ。何の体験かは書かれていない | あいまい |
| 得 | 書かれていない | 不足 |
| 次の行動 | 予約のページへのリンクあり | あり |

| 種類 | 件数 | 割合 |
| --- | --- | --- |
| 景色の写真 | 7 | 70% |
| ツアーの内容と空き | 2 | 20% |
| 参加者の声 | 0 | 0% |
| お知らせ | 1 | 10% |

10件のうち7件が景色の写真。参加者の声は0件。いちばん伝わっていないのは、体験の内容と空き（2件だけ）。
改善案：
- プロフィールの案：島の朝カヤック体験。定員6人・約2時間・初心者歓迎、1人 6,600円（税込）。空いている日は予約のページから。
- 次の10本の投稿案の題：当日の流れ／持ち物／初めての人の声／雨の日の判断と返金／朝の海の様子／ガイドの紹介／写真の撮り方／直近の空き／集合場所の行き方／よくある質問
- 投稿の案（そのまま使える文）：
  1. 島の朝カヤック体験。定員6人、約2時間、初心者歓迎です。1人 6,600円（税込）。空いている日は、プロフィールの予約のページから。
  2. 雨で中止の時は全額返金します。前日の夕方に、天気を見て連絡します。空きは予約のページから確かめられます。
  3. 当日の流れ：集合 7:00、説明 15分、漕ぐ 1時間30分、解散 9:00。持ち物は着替えと飲み物だけです。申し込みは予約のページから。
  （時刻・金額・条件は例。実際の値は持ち主に確かめる。）
先にやる1つ：投稿1の文をそのまま固定投稿にする。
引き継ぎメモ：
- 事業：少人数の体験ツアー（X）
- 目標：予約の確定を増やす
- 確認した数：投稿10件のうち、体験の内容と空きは2件、参加者の声は0件。反応は未確認
- いちばんの問題：何の体験かと得がプロフィールに書かれていない
- 先にやる1つ：体験の内容と料金の固定投稿
続けるなら：SNS 集客（10本の案を出し、予約のページへの訪問と確定で確かめる）。

### 決まり

- 持ち主への質問は、一度に1つだけ。
- この診断は何も送らない。投稿もしない。結果は持ち主の手元に置く。
- 他人のアカウント名・コメントの投稿者名など、個人の情報を表に入れない。
- 数を推測で埋めない。貼られていない反応の数は「未確認」。
- 投稿の数が少ない時の比べを、確かな効果として言わない。
- 成果を約束しない。

## チェックリスト

- プロフィールの点検の表を持ち主が見て直した
- 投稿の種類ごとの割合が、件数と合っている
- 未確認のもの（反応の数など）に印を付けた
- 投稿の案3本に、店名・商品・得・次の行動がそろっている
- 事実（値段・日数）は、貼られた内容か持ち主の確認で裏づけられている

## 終わりの目安

2つの表、改善案（次の10本の投稿案の題・投稿3本）、引き継ぎメモを、持ち主が見て合意した。

## 次にできること

- 投稿を出す前に flapbase-post-check で下書きを点検する。
- 投稿の下書きを増やすなら flapbase-post-assist。
- 運用の全体を組み直すなら flapbase-sns-operations。
