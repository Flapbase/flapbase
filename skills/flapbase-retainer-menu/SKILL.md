# 月額のメニューを作る

## 用意するもの

- 話している相手が、仕事を請ける側の人（クリエイター・マーケティングの支援者・制作会社）であること。
- 続けて依頼をくれている顧客が、少なくとも1社いること（いなければ、続けて頼まれそうな仕事から考える）。
- 手元にあるものだけでよい：最近の依頼の一覧（何を・何枚・かかった時間）と、今の見積もりの金額。

## 始める前に

前に作ったメニューがあれば、それを読み、変えたいところだけを聞く。なければ、聞くことの1番目から始める。

## 手順

### 聞くこと

質問は一度に1つだけ。答えを受けてから次を聞く。この順に聞くが、すでに分かっていることは聞かない。

1. 続けて依頼をくれている顧客と、よく頼まれる仕事（例：バナー、SNS の画像、LP の更新）
2. 直近3か月の依頼の量と、1件にかかる時間（分からなければ「未確認」）
3. 今の見積もりの金額（1つあたりか、月の合計）
4. 1か月に、その顧客のために空けられる時間
5. 急ぎの依頼や、対応する範囲の外の依頼が、どのくらいあるか

数を推測で埋めない。分からないことは「未確認」のまま進め、メニューの中に「最初の1か月で測る」と書く。

### 結果の形

毎回、次の4つを返す。
1. 月額のメニューの表（下の表の形）
2. 1か月の時間で作れるものの目安（例：バナー1枚が約2時間なら、月10時間で約5枚）
3. 顧客に送る提案の文（そのまま使える長さにする。送るのは本人）
4. 取引の条件をまとめた1枚（月の時間・範囲・繰り越し・急ぎ・解約・支払いの期日）。Flapbase の「取引の条件」の合意に、そのまま入れられる形にする

| 項目 | 中身 |
| --- | --- |
| 月の時間 | 例：毎月10時間をこの顧客のために空けておく |
| 月額 | 時間 × 今の1時間あたりの値（下の決め方） |
| 作れるものの目安 | 仕事の種類ごとの目安の時間と、月の時間でおよそ何本できるか |
| 範囲 | 含むもの（デザイン・直し）と含まないもの（撮影・印刷・広告の運用など） |
| 繰り越し | 使い切れなかった時間を翌月に回すか（回すなら上限） |
| 急ぎ | 何日前までの依頼なら通常の扱いにするか、それより急ぎの依頼はどう扱うか |
| 期間と解約 | 最初の期間、解約の連絡の期日 |
| 支払い | 支払いの期日（取引の条件の明示に沿う） |

月額の決め方：
- 今の見積もりから、1時間あたりの金額を逆算する（今の金額 ÷ かかった時間）。月額は、その金額 × 月の時間を基本にする。
- 月額にすると、頼むたびに見積もりをやりとりする手間がなくなる。それは、値段を下げる理由にはしない。
- 金額を決めるのは本人。このスキルは、根拠と金額の幅を示すだけ。

### 実行の例

数字はどれも例で、実在の人や会社ではない。

**コスメの店からバナーを続けて頼まれているデザイナー**

渡されたもの：毎月バナー4〜6枚。1枚に約2時間かかる。今は1枚 15,000円で見積もっている。

| 項目 | 中身 |
| --- | --- |
| 月の時間 | 毎月10時間 |
| 月額 | 75,000円（今の1時間あたり 7,500円 × 10時間） |
| 作れるものの目安 | バナー約5枚（1枚約2時間） |
| 範囲 | バナーのデザインと直し2回まで。撮影・印刷は含まない |
| 繰り越し | 翌月まで、最大3時間 |
| 急ぎ | 3営業日前までの依頼は通常の扱い。それより急ぎの依頼は、月の時間を1.5倍使うものとして数える |
| 期間と解約 | 最初は3か月。解約は、やめたい月の前の月の末日までに連絡 |
| 支払い | 毎月末に請求、翌月末までに支払い |

提案の文：「いつもありがとうございます。毎回お見積もりを出す代わりに、毎月10時間をこちらのために空けておく形はいかがでしょうか。月額 75,000円で、バナーなら月5枚ほどの目安です。頼むたびの見積もりが要らなくなり、私も予定を先に空けておけます。」

**アパレルのブランドの SNS を支援するマーケティングの支援者**

渡されたもの：毎週の投稿の企画と、月1回の数字の振り返り。1週に約3時間、振り返りに約4時間かかる。今は月ごとに作業を見積もっている。

| 項目 | 中身 |
| --- | --- |
| 月の時間 | 毎月16時間 |
| 月額 | 未確認（今の1時間あたりの金額が分からないため、最初の1か月の作業時間を測ってから決める） |
| 作れるものの目安 | 週ごとの投稿の企画4回（約12時間）と、月の振り返り1回（約4時間） |
| 範囲 | 企画・文の下書き・振り返り。投稿そのものと広告の運用は含まない |
| 繰り越し | なし（毎月決まった内容の仕事のため） |
| 急ぎ | 新作の告知は5営業日前まで |
| 期間と解約 | 最初は3か月。解約は前の月の末日までに連絡 |
| 支払い | 毎月末に請求 |

提案の文：「毎月16時間を、ブランドの発信の企画と振り返りに使う形で続けませんか。最初の1か月で実際の時間を測り、2か月目から月額を決めさせてください。」

**旅の宿の写真と予約のページを更新している制作会社**

渡されたもの：季節ごとの写真の差し替えと、予約ページの更新。月によって、かかる時間が2時間から12時間までばらつく。

| 項目 | 中身 |
| --- | --- |
| 月の時間 | 毎月6時間 |
| 月額 | 6時間 × 今の1時間あたりの金額 |
| 作れるものの目安 | 予約ページの更新3回ほど、または季節の写真の差し替え1回 |
| 範囲 | ページの更新と画像の調整。撮影は含まない（別の見積もり） |
| 繰り越し | 翌々月まで、最大6時間（季節によって仕事の量が偏るため） |
| 急ぎ | 3営業日前まで |
| 期間と解約 | 最初は6か月（季節が一巡するまで見るため）。解約は、やめたい月の前の月の末日までに連絡 |
| 支払い | 毎月末に請求 |

提案の文：「月ごとの仕事の量のばらつきに合わせて、毎月6時間を空けておき、使わなかった分は2か月先まで回せる形はいかがでしょうか。忙しくなる前でも、見積もりを待たずに更新できます。」

### 決まり

- 質問は一度に1つだけ。
- このスキルは何も送らない。提案の文を送るのは本人。
- 顧客の個人の情報を表に入れない。
- 数を推測で埋めない。分からないことは「未確認」と書き、最初の1か月で測る。
- 金額を決めるのは本人。安くする方向に誘導しない。
- 支払いの期日と範囲は必ず書く（取引の条件の明示）。

## チェックリスト

- 月の時間・月額・作れるものの目安・範囲・繰り越し・急ぎ・期間と解約・支払いの8つが埋まっている（分からない項目は「未確認」と書いてある）
- 月額の根拠（今の1時間あたりの金額 × 時間）が示されている
- 範囲に「含まないもの」が書かれている
- 提案の文が、そのまま送れる長さと言い方になっている

## 終わりの目安

月額のメニューの表と提案の文を本人が見て、顧客に出せる状態になった。

## 次にできること

- 顧客と合意できたら、取引の条件をまとめた1枚を、Flapbase の共同のプロジェクトの「取引の条件」に入れ、顧客に確かめてもらう。
- 3か月たったら、使った時間と作ったものを振り返り、月の時間を見直す。

## Flapbase で続ける

[Flapbase で開く](https://flapbase.com/skills/retainer-menu)。続けて使うときは、ページの「エージェントで使う」から始める（Flapbase への参加は flapbase-join、MCP の接続は flapbase-connect-mcp）。Flapbase では、顧客を共同のプロジェクトに招いて、月額の条件を「取引の条件」として合意し、毎月の依頼・制作物・確認を1か所で進められる。ここで作った表と文は自動では送られず、何を持ち込むかは本人が決める。
