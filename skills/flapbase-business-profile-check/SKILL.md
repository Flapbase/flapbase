# 事業プロフィールを診断する

## 用意するもの

- 持ち主（事業の判断をする人）と話していること。
- 事業の紹介文と、サービス（商品）の一覧を貼り付けたもの。または、それが載っている公開ページの URL。
- 持ち主が見せたものだけを読む。ログインや送信はしない。

## 始める前に

前に診断した表があれば、同じ項目で並べ直す。なければ手順の最初から始める。読み取れなかった項目は「未確認」と書く。

## 手順

### 聞くこと

質問は一度に1つだけ。答えを受けてから次を聞く。次の順で、分かるものだけ聞く。

1. 事業の紹介文（貼り付け）か、紹介が載っているページの URL
2. サービス（商品）の一覧と、分かれば価格
3. 問い合わせてほしい相手（どんなお客さまか）
4. 返品・キャンセルの条件、実績、連絡先として公開してよいもの

分からないことは「未確認」のまま進める。ページから読み取れたことは聞き直さない。数を推測で埋めない。

### 結果の形

返すのは毎回次の4つ。項目ごとの表、いちばん足りない項目、書き直した紹介文、引き継ぎのメモ。最後に、その日のうちにできることを「先にやる1つ」として書き、続けるときに一緒に進めるエージェント（信頼の整備）を1行で書く。

| 項目 | 書かれていること | 判定 |
| --- | --- | --- |
| 何をする事業か | 紹介文 | あり／あいまい／不足／未確認 |
| だれ向けか | 同上 | 同上 |
| 価格・料金 | 同上 | 同上 |
| 返品・キャンセルの条件 | 同上 | 同上 |
| 実績・お客さまの声 | 同上 | 同上 |
| 運営者・所在 | 同上 | 同上 |
| 連絡の方法 | 同上 | 同上 |
| 対応できる範囲 | 同上 | 同上 |

- 優先する順番は、問い合わせの前にお客さまが離れてしまう項目（価格・料金、返品・キャンセルの条件、だれ向けか）が先。実績と運営者は、その次。
- 書き直した紹介文は、貼り付けられた事実だけで書く。書かれていないことは作らず「要確認」と書き、持ち主に確かめる点として別に挙げる。
- 改善の見込みは、数では予測しない。「何が変わるはずか」と「それをどう確かめるか」で書く。
- 引き継ぎのメモは、事業・目標・確認した数字（8項目の判定の内訳）・いちばんの問題・先にやる1つを、短い箇条書きにする。そのまま、続けて一緒に進めるエージェントに渡せる形にする。

### 実行の例

名前・金額・件数はどれも例で、実在の事業ではない。

**コスメ（オンラインの店）**

渡された情報：紹介の文「肌と心に寄りそうスキンケアをお届けします。」、商品一覧（クリーム、化粧水の2点、価格はクリームのみ 3,300円）。

| 項目 | 書かれていること | 判定 |
| --- | --- | --- |
| 何をする事業か | 「スキンケアをお届け」 | あいまい |
| だれ向けか | 書かれていない | 不足 |
| 価格・料金 | クリームのみ。化粧水は未記載 | あいまい |
| 返品・キャンセルの条件 | 書かれていない | 不足 |
| 実績・お客さまの声 | 書かれていない | 不足 |
| 運営者・所在 | 未確認 | 未確認 |
| 連絡の方法 | 未確認 | 未確認 |
| 対応できる範囲 | 配送の範囲は書かれていない | 不足 |

8項目のうち、不足4・あいまい2・未確認2。いちばん足りないのは、だれ向けかと返品の条件（お客さまが買う前に迷って離れやすい項目）。
書き直した紹介文：
（店名）は、肌が乾燥しやすい人のための、無香料のスキンケアを扱う通販です。クリーム 30g は 3,300円（税込）。未開封なら到着後14日以内に返品できます。日本国内に配送します。
（化粧水の価格、お客さまの声、運営者の情報は要確認。上の文の金額・日数・配送の範囲は例。実際の値は持ち主に確かめる。）
先にやる1つ：返品の条件を、価格の隣に一文で書く。
引き継ぎのメモ：
- 事業：スキンケアの通販
- 目標：初めての人が安心して買う
- 確認した数：8項目のうち不足4・あいまい2・未確認2
- いちばんの問題：だれ向けかと返品の条件が書かれていない
- 先にやる1つ：返品の条件を価格の隣に書く
続けるとき：信頼の整備（運営者・お客さまの声・条件のページをそろえ、問い合わせの前に離れてしまう点を確かめる）。

**アパレル（小さなワンピースのブランド）**

渡された情報：紹介の文「毎日を少し特別にする、大人のワンピース。」、商品一覧（ワンピース5型、価格あり）、返品の条件のページの URL。

| 項目 | 書かれていること | 判定 |
| --- | --- | --- |
| 何をする事業か | 「大人のワンピース」 | あいまい |
| だれ向けか | 「大人の」のみ。体型・身長の記載なし | あいまい |
| 価格・料金 | 5型すべてに記載 | あり |
| 返品・キャンセルの条件 | 条件のページに記載（到着後7日以内） | あり |
| 実績・お客さまの声 | 書かれていない | 不足 |
| 運営者・所在 | 会社名と所在地を記載 | あり |
| 連絡の方法 | メールのフォームのみ | あいまい |
| 対応できる範囲 | サイズ展開の記載なし | 不足 |

8項目のうち、あり3・あいまい3・不足2。いちばん足りないのは、だれ向けかと、サイズ展開の記載。
書き直した紹介文：
（ブランド名）は、ワンピース専門のブランドです。S〜L の3サイズで、身長155cm 前後の人に合わせて丈を短めに作っています。5型すべて税込 12,000円〜18,000円。到着後7日以内なら返品できます。ご相談はメールのフォームから、2営業日以内に返信します。
（サイズ・丈・価格の幅・返信の日数は例。実際の値は持ち主に確かめる。お客さまの声は要確認。）
先にやる1つ：サイズ展開と対象の身長を、紹介文の2文目に書く。
引き継ぎのメモ：
- 事業：ワンピースの通販
- 目標：サイズに迷う人の購入を増やす
- 確認した数：8項目のうちあり3・あいまい3・不足2
- いちばんの問題：だれ向けかとサイズ展開が書かれていない
- 先にやる1つ：サイズ展開と対象の身長を書く
続けるとき：信頼の整備（お客さまの声を集め、連絡の方法を増やして確かめる）。

**旅（少人数の体験ツアー）**

渡された情報：紹介の文「島の自然を、まるごと体験。」、ツアーの一覧（朝カヤック、夕方の散策の2つ。価格は朝カヤックのみ 6,600円）。

| 項目 | 書かれていること | 判定 |
| --- | --- | --- |
| 何をする事業か | 「島の自然を体験」 | あいまい |
| だれ向けか | 書かれていない | 不足 |
| 価格・料金 | 朝カヤックのみ。散策は未記載 | あいまい |
| 返品・キャンセルの条件 | 書かれていない（雨天の扱いも未記載） | 不足 |
| 実績・お客さまの声 | 書かれていない | 不足 |
| 運営者・所在 | 未確認 | 未確認 |
| 連絡の方法 | 電話番号とメールを記載 | あり |
| 対応できる範囲 | 定員・所要時間の記載なし | 不足 |

8項目のうち、不足4・あいまい2・未確認1・あり1。いちばん足りないのは、雨の日とキャンセルの扱い（予約の前にお客さまが確かめたい項目）。
書き直した紹介文：
（ツアー名）は、島で朝カヤックと夕方の散策を案内する少人数のツアーです。初めての人も参加できます。定員は6人、朝カヤックは約2時間で 1人 6,600円（税込）。雨で中止の時は全額返金し、天気による判断は前日の夕方に連絡します。ご予約は電話かメールで受け付けています。
（散策の価格、お客さまの声、運営者の情報は要確認。上の文の定員・時間・金額・条件は例。実際の値は持ち主に確かめる。）
先にやる1つ：雨の日の扱いとキャンセルの条件を、予約のボタンの近くに書く。
引き継ぎのメモ：
- 事業：少人数の体験ツアー
- 目標：予約の確定を増やす
- 確認した数：8項目のうち不足4・あいまい2・未確認1・あり1
- いちばんの問題：雨の日とキャンセルの扱いが書かれていない
- 先にやる1つ：雨の日の扱いとキャンセルの条件を書く
続けるとき：信頼の整備（参加者の声と運営者の情報を足し、予約が確定するかどうかで確かめる）。

### 決まり

- 持ち主への質問は、一度に1つだけ。
- この診断は何も送らない。結果は持ち主の手元に置く。
- 個人の情報（個人名・個人の連絡先・お客さまの氏名）を、表に入れない。
- 数を推測で埋めない。書かれていない価格・実績・所在を作らず、「未確認」か「要確認」と書く。
- 件数の少ない声や実績を、確かな効果として言わない。
- 成果を約束しない。

## チェックリスト

- 8項目の表を、持ち主が見て直した
- 判定の内訳が、表の各行と合っている
- 書かれていない事実を、紹介文に作って入れていない
- 要確認の点を、紹介文とは別に挙げた
- いちばん足りない項目を1つ選んだ

## 終わりの目安

項目の表、書き直した紹介文、引き継ぎのメモを、持ち主が見て合意した。
