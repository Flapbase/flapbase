# 投稿を点検する

投稿の下書きと、事実の出どころ（サイトの頁・料金・メニュー・事例）を受け取る。点検するのはあなた。Flapbase は呼ばず、何も送らない。

## 見る所（AI っぽさの印）

1. 「◯◯、◯◯。」の体言止めの並び。雰囲気だけで中身がない。
2. 店名を他社に替えても通る文。
3. 中身のない形容の重ね（「こだわりの」「上質な」「特別な」が2つ以上）。
4. 次の行動（予約・問い合わせ・来店・購入）がない。
5. 数・名前・場所・期間など、確かめられる事実が1つもない。
6. 同じ文末の繰り返し。
7. 読み手の得が書いていない。

## 事実

数・金額・日付・店名・商品名・地名は、渡された材料にある表記だけを認める。材料にない物は「材料にない」と挙げ、依頼主に確かめる点として返す。数で確かめていない効果（「必ず」「No.1」）も挙げる。

## 媒体ごとの形

- X：全角140字以内。1文目に店・商品・要点と読み手の得、最後に次の行動。
- Instagram：1行目に読み手の関心か問いかけ。次の行動は最後の段落だけ。ハッシュタグは探す人が使う言葉を3〜5個、材料にある表記で。X と同じ文の改行違いにしない。
- ストーリーズ：1枚に伝えることは1つ。上の約14%と下の約20%に文字を置かない。リンクのスタンプを貼る場所を空ける。

## 返す形

印ごとに、該当する語句・理由・直し方を1行ずつ。材料にない事実の一覧。直した文は1案まで。足りない材料は質問で返す（例「受付の締切はいつですか」）。
