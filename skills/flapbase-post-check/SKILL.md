# 投稿を点検する

## 用意するもの

投稿の下書きと、事実の材料（サイトのページ・料金・メニュー・事例など）、投稿する媒体を用意する。

## 始める前に

材料にどんな事実があるかと、投稿する媒体の形式を確かめる。

## 手順

投稿の下書きと、事実の材料（サイトのページ・料金・メニュー・事例）を受け取る。点検するのはあなた自身で、Flapbase の道具は呼ばず、何も送らない。

### 見る点（AI っぽさの目印）

1. 「◯◯、◯◯。」のように、名詞で終わる短い言葉が並んでいる。雰囲気だけで、中身がない。
2. 店名を他の店の名前に替えても、そのまま通じてしまう文。
3. 中身のない形容が重なっている（「こだわりの」「上質な」「特別な」が2つ以上ある）。
4. 読み手に取ってほしい行動（予約・問い合わせ・来店・購入）が書かれていない。
5. 数・名前・場所・期間など、確かめられる事実が1つも書かれていない。
6. 同じ文末が繰り返されている。
7. 読み手にとっての得が書かれていない。

### 事実

数・金額・日付・店名・商品名・地名は、渡された材料にある表記だけを正しいものとして認める。材料にないものは「材料にない」と書き出し、依頼主に確かめてもらう点として返す。数字などの裏づけがない効果の言い切り（「必ず」「No.1」）も、同じように書き出す。

### 媒体ごとの形

- X：全角140字以内。1文目に店・商品・要点と読み手の得を書き、最後に読み手に取ってほしい行動を書く。
- Instagram：1行目に、読み手の関心を引く言葉か問いかけを置く。読み手に取ってほしい行動は、最後の段落にだけ書く。ハッシュタグは、探す人が使う言葉を3〜5個、材料にある表記で付ける。X の文と同じ内容を、改行だけ変えて使い回さない。
- ストーリーズ：1枚で伝えることは1つにする。画面の上の約14%と下の約20%には文字を置かない。リンクのスタンプを貼る場所も空けておく。

### 返す形

目印ごとに、当てはまる語句・その理由・直し方を1行ずつ書く。材料にない事実は一覧にして返す。直した文は1案までにする。足りない材料は、質問の形で返す（例「受付の締め切りはいつですか」）。

## チェックリスト

本文にある確認項目を、確認できたもの・確認できていないもの・人の判断を待つものに分けて示し、今回の対象に抜けがないかを確かめる。

## 終わりの目安

問題のある箇所・その理由・直す案と、確認できていない事実を返した。

## 次にできること

flapbase-sns-operations（SNS の運用）で、投稿したあとの記録と振り返りを進める。

## Flapbase で続ける

[Flapbase で開く](https://flapbase.com/skills/post-check)。ページの「エージェントで使う」に、手順と使う道具が載っている。専用のワークフローや Project は自動では作られない。ここで出した結果も自動では Flapbase に送られないので、続ける範囲と持ち込む材料を、人が確かめてから進める。
