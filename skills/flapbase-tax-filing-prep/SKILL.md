# 確定申告の準備

この skill がするのは準備と漏れの確認まで。税額の計算・どの特例を使うかの判断・申告書の作成と提出はしない。

## 決まり

- その年の期限・控除の額・様式・電子申告の手順は毎年変わることがある。この skill に日付や金額を書き込まず、毎回その年の公式の案内（国税庁の確定申告の頁、自治体の案内）を開いて確かめ、出典の URL を添える。
- 判断が分かれる所（経費にできるか・按分の割合・どの申告方法か）は、持ち主か税理士が決める。エージェントは材料と問いを並べるだけ。
- マイナンバー・口座番号・カード番号を記録やチャットに書かない。
- 「これで申告は正しい」と言わない。

## 原則のチェックリスト

### 1. 年の初めから（毎月）
- 売上の記録：請求と入金（Flapbase の請求と入金）、現金・カードの売上。
- 経費の証拠：領収書・請求書・明細を、月ごとに1か所へ（Flapbase なら受け箱に転送された請求のメール、リソース管理の固定費）。
- 事業と私用が混ざる物（家賃・通信・車両）は、按分の考え方を持ち主が決めて書いておく。
- 帳簿（会計の道具）に月ごとに入れる。

### 2. 年の終わりに
- 1年分の売上と経費がそろっているか、月の抜けがないか。
- 年をまたぐ取引（12月に納品・1月に入金など）の扱いを確かめる。
- 在庫・大きな買い物（設備・車両）・借入があるか。リソース管理の一覧と照らす。
- 控除に使う書類（保険・年金・医療・寄附など）が手元にあるか。

### 3. 申告の前に
- その年の期限と提出の方法（電子申告か紙か）を公式の案内で確かめる。
- 必要な書類の一覧を、公式の案内から作る（推測で作らない）。
- 前の年の申告書の控えと見比べ、大きく変わった所に理由があるか。
- 判断が要る所の問いの一覧を作り、持ち主か税理士に渡す。

### 4. 納付まで
- 納付の期限と方法（振替・電子・窓口）を確かめ、Flapbase のリソース管理の期限に入れる。
- 消費税・住民税・事業税など、ほかの納付の期限も同じ所に入れる（どれが自分に関係するかは公式の案内か税理士で確かめる）。
- 予定納税の通知が来るかを確かめる。

## Flapbase Cloud でつなぐ所

- 期限：リソース管理に「確定申告」「納付」を期限として入れ、カレンダーの見え方で見る。
- 書類：受け箱の請求のメール、請求と入金の記録、リソース管理の固定費から、月ごとの抜けを洗い出す。
- 手順：この一覧をワークフロー「確定申告の準備」の工程にし、月ごとの工程は自動の知らせに、判断の工程は人に。

## これから

その年の期限・閾値・控除の決まりは、Flapbase の UIR（法令と決まりの置き場。法令の ID と適用の期間つき）に版つきで置き、この skill はそこから読む形にする予定。それまでは公式の案内を毎回確かめる。
