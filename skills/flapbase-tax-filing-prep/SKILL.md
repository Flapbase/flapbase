# 確定申告の準備

## 用意するもの

対象の年と、依頼主が使ってよい書類・記録を用意する。

## 始める前に

集まった書類、足りない書類、公式の期限や様式を確認したかどうかを分けて整理する。

## 手順

このスキルがするのは準備と漏れの確認まで。税額の計算・どの特例を使うかの判断・申告書の作成と提出はしない。

### 決まり

- その年の期限・控除の額・様式・電子申告の手順は毎年変わることがある。このスキルに日付や金額を書き込まず、毎回その年の公式の案内（国税庁の確定申告のページ、自治体の案内）を開いて確かめ、出典の URL を添える。
- 判断が分かれる点（経費にできるか・按分の割合・どの申告方法か）は、持ち主か税理士が決める。エージェントは材料と問いを並べるだけ。
- マイナンバー・口座番号・カード番号を記録やチャットに書かない。
- 「これで申告は正しい」と言わない。

### 基本のチェックリスト

#### 1. 年の初めから（毎月行う）
- 売上の記録：請求と入金（Flapbase の請求と入金）、現金・カードの売上。
- 経費の証拠：領収書・請求書・明細を、月ごとに1か所へ（Flapbase なら受け箱に転送された請求のメール、リソース管理の固定費）。
- 事業と私用が混ざるもの（家賃・通信・車両）は、按分の割合の考え方を持ち主が決めて書いておく。
- 帳簿（会計の道具）に月ごとに入れる。

#### 2. 年の終わりに
- 1年分の売上と経費がそろっているか、月の抜けがないか。
- 年をまたぐ取引（12月に納品・1月に入金など）の扱いを確かめる。
- 在庫・大きな買い物（設備・車両）・借入があるか。リソース管理の一覧と照らす。
- 控除に使う書類（保険・年金・医療・寄附など）が手元にあるか。

#### 3. 申告の前に
- その年の期限と提出の方法（電子申告か紙か）を公式の案内で確かめる。
- 必要な書類の一覧を、公式の案内から作る（推測で作らない）。
- 前の年の申告書の控えと見比べ、大きく変わった点に理由があるか。
- 判断が必要な点について確かめたいことの一覧を作り、持ち主か税理士に渡す。

#### 4. 納付まで
- 納付の期限と方法（振替・電子・窓口）を確かめ、Flapbase のリソース管理の期限に入れる。
- 消費税・住民税・事業税など、ほかの納付の期限も同じ場所に入れる（どれが自分に関係するかは公式の案内か税理士で確かめる）。
- 予定納税の通知が来るかを確かめる。

### Flapbase Cloud での使い方

- 期限：リソース管理に「確定申告」「納付」を期限として登録し、カレンダー表示で確認する。
- 書類：受け箱の請求のメール、請求と入金の記録、リソース管理の固定費から、月ごとの抜けを洗い出す。
- 手順：この一覧をワークフロー「確定申告の準備」の工程にする。月ごとの工程は自動の通知にし、判断が必要な工程は人が担当する。

### 今後の予定

将来は、その年の期限・基準額・控除の決まりを、Flapbase の UIR（法令や決まりを、法令の ID と適用期間つきで保管する場所）に版を分けて保存し、このスキルがそこから読み込む形にする予定。それまでは、公式の案内を毎回確かめる。

## チェックリスト

手順で確かめた項目を「確認済み」「未確認」「持ち主の判断待ち」に分けて書き出し、抜けがないかを確かめる。

## 終わりの目安

準備ができたもの、不足しているもの、専門家に確認する項目と期限を一覧にした。
