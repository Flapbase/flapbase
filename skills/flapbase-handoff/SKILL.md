# 引き継ぎの記録を残す

## 用意するもの

対象の仕事と、成果物・判断・未完了の作業の記録を用意してください。

## 始める前に

元となる正しい資料の置き場所と最新の版を確かめ、次の担当が見られる範囲も確かめてください。

## 手順

次に読む人（またはエージェント）は、これまでの会話を見ていません。引き継がれるのは、Flapbase の中に残したものだけです。

### 残す場所

| 残すもの | 場所 | 道具 |
| --- | --- | --- |
| 成果物 | Project に保存した下書きの版 | `site_create`・`site_apply`・`design_save` など |
| 成果物の確認 | 工程に紐づけた版 | `work_item_submit` |
| 決めたこと・直したこと・受けた意見 | 工程の記録 | `work_item_note` |
| 人に決めてほしいこと | 判断の依頼 | `decision_request_create` |
| 実行した手順の流れそのもの | テンプレート | `workflow_template_save` |

### 制作物とやりとりの置き場所

相手（依頼主・制作者・協力者）とのやりとりは、メール・チャット・共有フォルダに散らばりがちです。次の決まりで、1か所にまとめます。

| 対象 | 置き場所 | 理由 |
| --- | --- | --- |
| Flapbase で作るもの（サイト・デザイン・記事・投稿・動画・音楽・仕様の文書） | Flapbase の Project（これが元となる正しい資料） | 版・確認・承認・履歴が1か所に残り、相手も次のエージェントも、同じものを見られる |
| 相手から預かるもの（資料・PDF・大きな素材・会議の文字起こし） | Google Drive など元の場所のまま。Project からは、その1件を参照する | 相手に置き場所を移してもらう手間をかけない。大きなファイルの保管は、持ち主の側に残す |
| 確認・返事・決まったこと・次の仕事 | Project の工程と記録（`work_item_submit`・`work_item_note`・`decision_request_create`） | 何を決めたか、今どこまで進んだか、次にだれが何をするかを、そのつど集め直さずに済む |

- メール・チャット・会議で決まったことは、Project の工程の記録に1行で残します（だれが・何を・いつまでに）。
- 制作物のコピーを Drive やメールに置いて、そちらを元の資料にしないでください。相手に送るときは、Project の版を示します。
- 相手が Flapbase を使っていなくても、Project に招待すれば、自分宛ての版を確認して返事ができます。今のやり方（Drive・メール）をやめてもらう必要はなく、Project を示す1行を添えれば足ります。

### 作業の区切りでやること

1. 保存していない案や修正を、`site_apply` か `design_save` で下書きとして保存します。
2. `work_item_update` で、工程の状態を今の状況に合わせます。止まっている場合は blocked にして、その理由を `work_item_note` に書きます。
3. `work_item_note` に、次のことを短く書き残します。
   - 何を作ったか（Project の中の成果物と、その版）。
   - 何を決めたか、だれが決めたか（種類は `decision`）。
   - 直したこと（種類は `change`）と、受けた意見（種類は `feedback`）。
   - 次にやること、人の判断を待っていること。
4. `workflow_get` を読み直して、残した内容が表示されることを確かめます。

### 読む側のとき

- 最初に `workflow_get` を読みます。工程の状態、記録、今だれが担当しているか、始められる工程を確かめてから動いてください。
- 記録にないことを、推測で補ってはいけません。分からないことは、`decision_request_create` で人に聞いてください。

### 書かないこと

- 個人の連絡先・契約の金額・鍵やトークンは、記録に書かないでください。

## チェックリスト

手順で確かめた項目を「確認済み」「未確認」「持ち主の判断待ち」に分けて書き出し、抜けがないかを確かめてください。

## 終わりの目安

次の担当が、成果物・判断・残っている作業の記録を、読める状態になっている。

## 次にできること

flapbase-projects-tasks で、残っている工程を進めます。

## Flapbase で続ける

[Flapbase で開く](https://flapbase.com/skills/handoff)。公開のスキルページの「エージェントで使う」で、手順と使う道具を確かめてから続けてください。このスキルには専用のワークフローはなく、Project も自動では作られません。手元の結果も自動では送られないので、続ける範囲と持ち込む材料は、人が確かめてから決めてください。
