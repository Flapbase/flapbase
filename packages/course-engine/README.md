# Flapbase course engine

The standard Course Document validator, participation rules and learner access orchestration are shared by Cloud and self-hosted projects. Supply a repository that verifies the current learner and resolves the purchased or assigned immutable course revision. The engine filters lesson content and applies progress changes through that repository.
