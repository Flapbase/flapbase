# Security

Please do not report security issues in public.

Report them privately from the Security tab of this repository: Security → Report a vulnerability. Include the affected command or skill, the version, and the steps to reproduce.

## 日本語

セキュリティの問題は公開の場に書かないでください。このリポジトリの Security タブの「Report a vulnerability」から、非公開で報告してください。対象のコマンドか skill、版、再現の手順を添えてください。
